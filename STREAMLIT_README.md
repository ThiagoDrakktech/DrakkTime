# 🕐 DrakkTime - Streamlit (Interface Moderna)

Versão **moderna, fluida e responsiva** do DrakkTime usando Streamlit.

## 🚀 Como Usar

### Passo 1: Instalar Streamlit
Clique 2x em: **`INSTALAR_STREAMLIT.bat`**

(vai instalar Streamlit + Pandas)

### Passo 2: Executar
Clique 2x em: **`EXECUTAR_STREAMLIT.bat`**

A interface vai abrir no navegador automaticamente! 🌐

---

## ✨ Características da Nova Interface

- 🎨 **UI Moderna**: Streamlit Material Design
- 📱 **Responsiva**: Adapta para mobile, tablet e desktop
- ⚡ **Fluida**: Sem travamentos, muito rápida
- 🌓 **Tema**: Claro/Escuro automático (Windows)
- 📊 **Tabelas**: Interativas e ordenáveis
- 📥 **Exportação**: CSV com um clique
- 🎯 **Sidebar**: Menu simples e intuitivo

---

## 📋 Funcionalidades

### 👤 Funcionários
- Adicionar funcionários com cargo e modo sábado
- Ver lista atualizada em tempo real
- Remover com um clique

### ⏱️ Ponto
- Registrar entrada, saída, intervalo
- Suporte para retorno pós-expediente
- Histórico de registros do dia

### 📊 Resumo
- Cálculo automático de horas extras
- Tabela consolidada por funcionário
- Métricas: Total horas, total minutos, total funcionários
- **Exportar CSV** para relatório

---

## 🌐 Interface

A interface abre em `http://localhost:8501`

Para parar: Pressione **Ctrl+C** no terminal

---

## 💡 Dicas

- Mantenha o terminal aberto enquanto usa
- A interface recarrega automaticamente ao enviar dados
- Tema se adapta ao seu sistema operacional
